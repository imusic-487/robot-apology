# The Robot Apology

A make.fun bounty entry: a program that writes a two-line robot confession
to `/output/entry.txt` — one sentence owning a specific mistake, one naming
the lesson learned and the fix.

## Entry

> I am sorry I put salt in your coffee this morning instead of sugar; I picked the jar by its shape and never read its label.
> I have learned to read the label before I pour, so from now on I check every jar twice before it reaches your cup.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes the two-line confession to `/output/entry.txt` (239 characters,
UTF-8 plain text).
